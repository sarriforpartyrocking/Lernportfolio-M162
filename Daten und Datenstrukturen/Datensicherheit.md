- **Personenbezogene Daten** → Daten, die sich auf eine Person beziehen oder eine Person identifizierbar machen.
- **IP-Adressen** können personenbezogene Daten sein.
- Je mehr Daten miteinander **verknüpft** werden, desto grösser wird das Datenschutzrisiko.
- Durch Kombination verschiedener Merkmale kann eine Person auch **ohne Namen identifiziert** werden.

### Beispiel

Verkaufszahlen:
- pro **Ortschaft**  
- pro **Alter**  
- pro **Geschlecht**  
- pro **Beruf**

Je genauer die Daten aufgeteilt werden, desto kleiner wird die Gruppe.  
Wenn am Ende nur **ein Datensatz** übrig bleibt, kann möglicherweise auf eine bestimmte Person geschlossen werden.
