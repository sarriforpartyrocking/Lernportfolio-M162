
## Datensicherheit

- Schutz von Daten vor **unbefugter Veränderung**
- Ziel: **Integrität** der Daten gewährleisten
- Daten müssen für zuverlässige Auswertungen **vollständig, korrekt und unverändert** sein
- Wichtige Massnahmen:
    - Zugriffsberechtigungen
    - Datensicherungen
    - Protokollierungen
- Sensible Arbeitsdaten während der Auswertung schützen
- Temporäre Daten nach der Auswertung löschen bzw. bereinigen
- Auch an **Logfiles, temporäre Dateien und Copy&Paste-Zwischenspeicher** denken

**Datensicherheit = Daten vor Verlust, Veränderung und unbefugtem Zugriff schützen.**

## Datenschutz

- Schutz von **personenbezogenen Daten**
	-   **Personenbezogene Daten** → Daten, die sich auf eine Person beziehen oder eine Person identifizierbar machen.
	- Je mehr Daten miteinander **verknüpft** werden, desto grösser wird das Datenschutzrisiko.
	- Durch Kombination verschiedener Merkmale kann eine Person auch **ohne Namen identifiziert** werden.
- Beispiele:
    - Name
    - Adresse
    - Geburtsdatum
    - E-Mail-Adresse
    - IP-Adresse
    - Kundennummer
    - Standortdaten
- Durch das Kombinieren von Daten können detaillierte **Persönlichkeits-, Verhaltens- oder Leistungsprofile** entstehen
- Deshalb gilt das Prinzip der **Datenminimierung**:
    - Nur Daten verwenden, die für den jeweiligen Zweck wirklich notwendig sind
- Wenn möglich:
    - **Pseudonymisierung**
    - **Anonymisierung**
### Beispiel aus dem Unterricht

Verkaufszahlen:
- pro **Ortschaft**  
- pro **Alter**  
- pro **Geschlecht**  
- pro **Beruf**

Je genauer die Daten aufgeteilt werden, desto kleiner wird die Gruppe.  
Wenn am Ende nur **ein Datensatz** übrig bleibt, kann möglicherweise auf eine bestimmte Person geschlossen werden.
